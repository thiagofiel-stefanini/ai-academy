# 02 · Code Review

O code review é o processo de revisão de código que acontece após a abertura de um pull request. Trata-se de uma etapa fundamental no desenvolvimento, em que avaliamos se o código está correto, funcional, legível e livre de bugs antes de integrá-lo à base principal.

No projeto anterior, ainda não consegui concluir o code review na prática devido à instabilidade temporária nos servidores. Porém, assim que retomarmos a atividade, farei a revisão seguindo as boas práticas, como analisar detalhadamente as alterações feitas (o diff), verificar se a nova rota segue o padrão REST do projeto e deixar feedbacks construtivos antes de aprovar o merge.

O conselho do vídeo que mais me chamou a atenção foi mostrar que o code review é uma via de mão dupla de aprendizado: beneficia tanto quem escreveu o código, que recebe um feedback externo, quanto quem está revisando, que tem a oportunidade de treinar a leitura de código alheio e aprender abordagens novas com a solução do colega. Como estou começando na área, vejo nisso uma ótima forma de acelerar meu aprendizado, assim como as revisões de projeto faziam na minha carreira anterior como projetista mecânico.
